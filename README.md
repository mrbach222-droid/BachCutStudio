# BáchCut Studio

Native SwiftUI / AVFoundation iPhone video editor. Current release candidate: **0.4.0**, iOS 16+.

- Separate saved projects with autosave, migration from the 0.3 project, portable media paths, undo / redo.
- Video timeline with thumbnails, playhead tracking, exact seek, trim, split at playhead, duplicate, delete, reorder, speed and source volume.
- V2 picture-in-picture video overlays and A2 music at the current playhead. Long-press their timeline rows to remove or adjust music volume.
- Original / 9:16 / 16:9 / 1:1 canvas. Mixed-orientation clips use per-clip aspect-fit transforms in both preview and export.
- Portrait and Landscape Pro without recreating editing state.
- MP4 export, share to Files and save to Photos. No watermark.

## Validation
GitHub Actions generates the Xcode project, runs XCTest model/storage tests, real AVFoundation export tests (frame colors, duration, orientation, audio waveform and overlays), and XCUITest portrait/landscape, playback, undo/redo, export and app relaunch tests. It builds and validates the device IPA only after tests pass. Logs and `.xcresult` are uploaded even on failure. Native-layer regression tests require real displayed frames and advancing player time for imported and restored projects. Hosts without a Metal device use a temporary rendered preview; devices with Metal use live composition. Preview files are removed when replaced or the editor closes.

This remains an early native editor. It does not claim CapCut feature parity. Animated titles, transitions, effects, captions, AI tools and arbitrary-position multi-track trimming are future work. Simulator validation does not replace testing on a physical iPhone. Imported media is retained when removing a project so shared sources and undo are not destroyed; automatic orphan cleanup is not yet included.

## Build
Use the `BachCutStudio` scheme generated by XcodeGen. GitHub Actions → **Build BáchCut Studio IPA** builds the unsigned IPA. Sign the IPA with your certificate before installation.
