# BáchCut Studio

Native SwiftUI / AVFoundation iPhone video editor. Current release candidate: **0.16.0**, iOS 16+.

- Import from Photos or Files either at the end or at the captured playhead. Inserting inside a clip splits its source range correctly at its speed; the complete selected batch is inserted in order with one Undo/Redo step. Cuts snap within 50 ms to avoid tiny fragments. Music and overlay offsets remain absolute. The selection is validated before committing; failure removes imported copies and leaves the project untouched.
- Separate saved projects with autosave, migration from the 0.3 project, portable media paths, undo / redo.
- Native UICollectionView timeline with a fixed central playhead, precise center timecode, magnetic cut-boundary snapping, native two-finger pinch zoom that keeps the playhead stationary, drag-to-scrub, coalesced seeks, inertial scrolling, long-press clip reorder with equal-width compact thumbnails, a visible insertion gap, constrained drag feedback and continuous edge scrolling, trim, split, duplicate, speed and source volume. Up to 20 sampled frames per clip show the scene progression; frames are cached until that clip's source, trim or speed changes. Cells are reused and only visible ruler/track marks are drawn.
- Native edge grips cut or extend the selected main clip and every music/overlay track directly on the timeline. Drag previews update locally; releasing commits one Undo/Redo step. Main clips ripple; a secondary in-point keeps its out-point fixed and updates source start with its offset. Bounds respect original media, speed, and the base timeline. VoiceOver adjusts a grip by 0.1 seconds; canceling or rotating during a drag discards its preview.
- V2 picture-in-picture video overlays and A2 music at the current playhead. Move secondary tracks directly by dragging or use precision timeline/source-start/duration controls. Select a section from anywhere in the original music or overlay video; preview and export use that selected source interval. Undo/redo and saved projects preserve source trims; older audio projects default to source start zero.
- Original / 9:16 / 16:9 / 1:1 canvas. Mixed-orientation clips use per-clip aspect-fit transforms in both preview and export.
- Portrait and Landscape Pro without recreating editing state. Landscape media buttons share the project-header row so the expanded secondary track grips remain reachable.
- MP4 / MOV H.264 + AAC export with 480p–4K short-edge resolution, 24/25/30/50/60 fps and 5–100 Mbps target bitrate. Choose H.264 or H.265/HEVC for MP4/MOV. AVAssetReader/Writer applies selected settings to actual frames and audio. Animated GIF export (240–480p, 5/10 fps, up to 30 seconds), progress, cancellation, Files sharing and Photos saving. No watermark. Upscaling and frame duplication do not create extra source detail; AI UHD, optical flow and HDR conversion are not implemented.

## Validation
GitHub Actions generates the Xcode project, runs XCTest model/storage tests, real AVFoundation export tests (frame colors, duration, orientation, audio waveform and overlays), and XCUITest portrait/landscape, playback, undo/redo, export and app relaunch tests. It builds and validates the device IPA only after tests pass. Logs and `.xcresult` are uploaded even on failure. Native-layer regression tests require real displayed frames and advancing player time for imported and restored projects. Original-size clips with identity transforms play directly from the composition. Rotated clips, changed canvas geometry and overlays use a temporary composed MP4 preview for reliable displayed frames; preparing a new complex preview takes additional time. Up to three completed previews, totaling at most 256 MiB, are retained per editor for reuse on Undo/Redo. Eviction and closing the editor remove cached files; deleted entries are regenerated. Selecting a video clip pauses at its start, stale end notifications cannot move a new edit point, and seeks made during preview preparation are preserved.

The UI suite also drags music and overlay blocks using actual touch gestures, checks one-step Undo/Redo and persisted offsets after relaunch, and verifies music/overlay source selection, Undo/Redo and relaunch. The edge-trim suite checks real touch drags, history, relaunch, source/speed bounds, ripple behavior, and the actual exported selected frames and audio. It captures the project library, portrait/landscape multi-track editor, source controls and export settings. Generated color videos and a sine tone are test fixtures, not user media.

This remains an early native editor. It does not claim CapCut feature parity. Animated titles, transitions, effects, captions, AI tools are future work. Simulator validation does not replace testing on a physical iPhone. CapCut-equivalent performance is not claimed; 4K/many-layer latency, memory and thermal behavior require physical-device benchmarks. Very wide/tall original aspect ratios must use a lower resolution if the long edge exceeds 4096 pixels. GIF limits prevent unbounded image export. Imported media is retained when removing a project so shared sources and undo are not destroyed; automatic orphan cleanup is not yet included.

## Build
Use the `BachCutStudio` scheme generated by XcodeGen. GitHub Actions → **Build BáchCut Studio IPA** builds the unsigned IPA. Sign the IPA with your certificate before installation.
